# Instruction Document: Rails Task Manager

Welcome! This is a Ruby on Rails application designed to teach non-CS students how to build their first web app. It includes an integrated, step-by-step tutorial (Lessons 0-6) that you can follow directly in your browser.

---

## 🛠️ Pre-Requisites
Before you can run this app, you must have **Ruby** and **Rails** installed on your computer. 
* If you don't have them yet, don't worry! Once you get the app open, **Lesson 0** will walk you through the setup.

---

## 🏃 Launch Instructions
Follow these steps in your terminal to get the tutorial running on your computer:

1. **Install the project tools:**
   $ `bundle install`

2. **Setup the database and lessons:**
   $ `rails db:prepare db:seed`

3. **Start your local server:**
   $ `rails server`

4. **Open your browser and go to:**
   [http://localhost:3000/lessons](http://localhost:3000/lessons)

---

## 📖 What You Will Learn
This project covers the absolute basics for beginners:
* **Lesson 0:** VS Code & Terminal Basics (For non-CS students).
* **Lesson 1:** What are Ruby and Rails?
* **Lesson 2-3:** Installation and App Creation.
* **Lesson 4-5:** Developing and Operating your app.
* **Lesson 6:** Personalizing your app (5 custom project ideas).

---

## 💡 Tips for Beginners
* **Commands:** When you see a command starting with `$`, do not type the `$`. Only type the text after it.
* **Stopping:** To stop the server, go to your terminal and press `Ctrl + C`.
* **Errors:** If you see a "Migrations are pending" error, just run `rails db:migrate` in your terminal.
